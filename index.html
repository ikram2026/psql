PostgreSQL Backup and Restore Basics

PostgreSQL supports SQL dumps, file system backups, and continuous archiving/PITR. 

pg_dump -U postgres -d mydb -F c -f mydb.backup
pg_restore -U postgres -d mydb mydb.backup

VACUUM and ANALYZE

VACUUM helps clean dead tuples, while ANALYZE updates planner statistics. 

VACUUM ANALYZE;

Check Active Connections

SELECT pid, usename, datname, state, query
FROM pg_stat_activity
ORDER BY query_start DESC;

Useful DBA Scripts

Database Size

SELECT datname, pg_size_pretty(pg_database_size(datname)) AS size
FROM pg_database
ORDER BY pg_database_size(datname) DESC;

Table Size

SELECT relname AS table_name,
       pg_size_pretty(pg_total_relation_size(relid)) AS total_size
FROM pg_catalog.pg_statio_user_tables
ORDER BY pg_total_relation_size(relid) DESC;
